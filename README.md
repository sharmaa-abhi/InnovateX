# Notion Unlocked × Nerds Room

A Notion-inspired event workspace for **Learn. Build. Organize.**

## Highlights

- Floating popup navigation with Overview, Agenda, Audience, Team and FAQ links.
- Document-style event page with Notion-inspired blocks and callouts.
- Responsive agenda database with desktop table and mobile cards.
- Accessible FAQ and event-detail toggles with keyboard support.
- People directory for the organizing team.
- Subtle scroll-reveal animation with `prefers-reduced-motion` support.
- Direct Luma registration CTA and Google Maps venue link.

## Tech stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run build
npm run preview
```

The local development server runs at `http://127.0.0.1:5173/`.
